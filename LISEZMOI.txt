📝 CHECKLIST INSTALLATION
═══════════════════════════════════════════════════════════════════════════════

Phase 1 : OVH (10 min)
☐ Créer sous-domaine noia.votre-domaine.fr
☐ Noter identifiants MySQL

Phase 2 : FTP (5 min)
☐ Uploader tous les fichiers dans /www/noia/
☐ Créer dossier /logs/ avec permission 755

Phase 3 : Base de données (5 min)
☐ Ouvrir phpMyAdmin
☐ Importer database_init.sql
☐ (Optionnel) Importer donnees_supplementaires.sql

Phase 4 : Configuration (3 min)
☐ Éditer config/config.php
☐ Remplir DB_HOST, DB_NAME, DB_USER, DB_PASS

Phase 5 : Test (2 min)
☐ Accéder à test.php
☐ Vérifier tous les tests ✅
☐ Supprimer test.php

Phase 6 : Make.com (10 min)
☐ Créer compte Make
☐ Créer scénario (Webhook → OpenAI → Response)
☐ Copier URL webhook dans config.php
☐ Activer scénario

Phase 7 : Test final (2 min)
☐ Ouvrir l'interface NOIA
☐ Poser une question test
☐ Valider la réponse !
